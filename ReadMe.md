# MugTrap

MugTrap is a static site repository for https://mugtrap.dev, A site focused on technology engineering tactics and architecture strategy.

## Contributing
Comments, issues, and feature requests are welcome. General comments are consolidated by Giscuss at: https://github.com/jbilinski/jbilinski.github.io-discussion/discussions/categories/mugtrap-comments

## Built using

- [Zola](https://www.getzola.org/) - A Rust SSG using [Tera](https://tera.netlify.app/) for templating.
- [Zola Theme - tabi](https://github.com/welpo/tabi)

- [Cloudflare Workers](https://workers.cloudflare.com/) - A serverless platform to run code at the edge.
- [Cloudflare Pages](https://pages.cloudflare.com/)- A _free_ hosting service for static sites.
